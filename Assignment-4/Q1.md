# Question 1 — Build the state |01⟩

Goal: Prepare |01⟩ from |00⟩ using one gate and confirm outcome.

Prediction & math:
- Start state: |00⟩ = [1, 0, 0, 0]^T.
 a two-qubit system starts in:  ∣00⟩ = ∣0⟩⊗∣0⟩

To reach 
∣01⟩, we need the second qubit to flip from ∣0⟩ to ∣1⟩.
That’s exactly what the Pauli-X gate (NOT gate) does.
So we apply: 𝐼⊗𝑋 
where 𝐼 acts on the first qubit (leaving it as ∣0⟩) and 𝑋 flips the second qubit.

(𝐼⊗𝑋) ∣00⟩ = ∣01⟩

In vector form, ∣01⟩  is represented as:

When we print the state vector, we should see: [0, 1, 0, 0]^T


- To create |01⟩, we must flip the second qubit in the computational basis.
- In the usual textbook notation, applying X to the second qubit gives |01⟩.
- In IBM Quantum Composer, the measured bitstring follows the platform’s qubit-ordering convention, where the top wire is q[0] and the bottom wire is q[1].
- So: applying X to q[1] (the lower wire) gives the measured result `10`, while applying X to q[0] (the upper wire) gives the measured result `01`.
- The physical operation is still the same single-qubit X gate; the difference is only the qubit-order convention used by the display.

Circuit (IBM Quantum Composer):
- Two qubits.
- Apply `X` to the upper qubit (`q[0]`) if we want the result to match the textbook state |01⟩.
- If we instead apply `X` to the lower qubit (`q[1]`), the measured output will be `10`, which is also correct under IBM’s ordering convention.

Expected measurement:
- If we apply X to q[0], the histogram shows 100% at `01`.
- If we apply X to q[1], the histogram shows 100% at `10`.
- Both are valid because the qubit index ordering in the Composer display is reversed relative to the textbook bitstring convention.
