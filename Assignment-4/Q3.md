# Question 3 — CNOT from H and CZ only

Goal: Build an exact CNOT using only `H` and `CZ` (no `CX`) and verify matrix equality.

Construction and math:
  - Identity: CNOT_{control,target} = (I ⊗ H) · CZ_{control,target} · (I ⊗ H)
  - Apply `H` to the target before and after a `CZ` acting between control and target.

Proof sketch (matrix-level):
- `CZ` = diag(1,1,1,-1) in the computational basis.
- Conjugating `CZ` by H on the target transforms the conditional phase into a conditional bit-flip (i.e., CNOT).

   - |00⟩ -> |00⟩
   - |01⟩ -> |01⟩
   - |10⟩ -> |11⟩
   - |11⟩ -> |10⟩
