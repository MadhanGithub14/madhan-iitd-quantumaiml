# Question 6 — SWAP from CNOTs only

Goal: Build SWAP using only CNOT gates (no swap primitive) and verify matrix equality.


SWAP matrix:
<img width="217" height="100" alt="image-9" src="https://github.com/user-attachments/assets/253b9c7c-df5e-4404-bf17-80e7b6ea63d8" />


Construction and math:
- Standard decomposition: SWAP_{a,b} = CNOT_{a,b} · CNOT_{b,a} · CNOT_{a,b}.

Truth mapping check:
- This sequence swaps the computational states of the two qubits exactly.

Composer build:
1. Two qubits.
2. Apply `CX` with control qubit0, target qubit1.
3. Apply `CX` with control qubit1, target qubit0.
4. Apply `CX` with control qubit0, target qubit1.
5. Verify by preparing basis inputs and checking outputs (or compare unitaries if available):
   - |01⟩ -> |10⟩, |10⟩ -> |01⟩, |00⟩ -> |00⟩, |11⟩ -> |11⟩.
