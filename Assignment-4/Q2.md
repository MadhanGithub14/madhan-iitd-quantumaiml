# Question 2 — Toffoli gate prediction
# Predict the final outcome of the described 3 qubit circuit before building it, then confirm your prediction.

The Toffoli gate (CCNOT) acts on three qubits:
	Two control qubits
	One target qubit The target flips (0 ↔ 1) only if both controls are 1.

Suppose the input state is ∣110⟩:
	Controls = 1 and 1 → both active.
	Target = 0 → flips to 1. So the output is  ∣111⟩.
If the input is ├ ∣111⟩:
	Controls = 1 and 1 → both active.
	Target = 1 → flips to 0. So the output is ∣110⟩.
For all other basis states (like ∣000⟩,∣010⟩,∣100⟩), the target remains unchanged.

Assumed (common) circuit:
- Qubits: control A = qubit 0, control B = qubit 1, target = qubit 2.
- Assume input state |110⟩ (controls both 1, target 0) — adjust if your initial state is different.

Prediction & math (for assumed |110⟩):
- Toffoli (CCX) flips target if both controls are 1.
- Input |110⟩ => both controls 1, target 0 => target flips to 1 => output |111⟩.

How to verify in Composer:
1. Create 3 qubits, prepare initial state (use `X` on qubits as needed, e.g., `X` on qubit0 and qubit1 to make |11?>).
2. Add `CCX` (Toffoli) with controls qubit0/qubit1 and target qubit2.
3. Measure and run; capture screenshot.
