# Question 4 — CNOT on an already-1 control

Task: Predict result of applying CNOT to state |11⟩, then confirm.

Prediction & math:
- Input: |11⟩ (control=1, target=1).
- CNOT flips the target when control is 1.
- Target 1 flips to 0, so output is |10⟩.

Composer build:
1. Two qubits.
2. Prepare |11⟩ by applying `X` to both qubits.
3. Apply `CX` with qubit0 as control and qubit1 as target.
4. Measure; expected histogram: 100% at `10`.
