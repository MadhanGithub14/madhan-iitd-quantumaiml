# Question 5 — Two independent Hadamards

Task: Predict histogram for two independently Hadamard qubits, then confirm.

Prediction & math:
- Start |00⟩.
- Apply `H` on each qubit: (H ⊗ H) |00⟩ = (1/2) (|00⟩ + |01⟩ + |10⟩ + |11⟩).
- Probabilities: each of the four basis states has probability |1/2|^2 = 1/4.

Expected histogram:
- Four equal bars at `00`, `01`, `10`, `11` each at 25%.

Composer build:
1. Two qubits.
2. Apply `H` to qubit0 and `H` to qubit1 (independently).
